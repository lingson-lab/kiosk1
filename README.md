# 링스온 힐스테이트 커뮤니티센터 키오스크

입주민용 시설 예약 키오스크 화면(퍼블리싱)입니다. 빌드 과정 없이 `index.html`을 브라우저로 열면 바로 동작합니다.

- 대상 화면: **1080 × 1920 세로형 키오스크**
- 기술: 순수 HTML / CSS / JavaScript (프레임워크 없음)

## 폴더 구조

```
linkson-kiosk/
├─ index.html        # 인트로·홈 마크업, 공통 레이어(메뉴/모달/토스트)
├─ css/style.css     # 전체 스타일
├─ js/app.js         # 화면 전환(해시 라우팅), 예약 화면 렌더링, 키오스크 설정
├─ images/           # 실제 시안 이미지를 넣을 폴더 (현재 비어 있음)
└─ README.md
```

## 화면 구성

| 해시 | 화면 |
|---|---|
| `#intro` | 인트로 (입장하기) |
| `#home` | 홈 (시설 메뉴) |
| `#golf` | 골프 타석 배정 |
| `#screen` | 스크린골프 예약 |
| `#kids` | 키즈카페 예약 |
| `#reading` | 독서실 일권 예약 |
| `#history/pay` · `/course` · `/usage` · `/golf` | 이용내역 (결제·수강·이용·골프내역 탭) |

## 키오스크 설정

### 화면 스케일
디자인 기준 폭 540px을 화면 크기에 맞춰 비율대로 확대합니다. 1080×1920에서는 정확히 2배로 표시되고, 비율이 다른 화면에서는 가운데 정렬된 9:16 영역으로 표시됩니다. (`css/style.css` 상단 `html{font-size:...}`)

### 무입력 시 인트로 복귀
`js/app.js` 상단의 값을 바꾸면 됩니다.

```js
const KIOSK = {
  IDLE_SECONDS: 60   // 이 시간(초) 동안 터치가 없으면 인트로로 돌아가고 입력값을 초기화
};
```

### 실행
- 로컬: `index.html`을 더블클릭해 브라우저로 열기
- Chrome 전체화면 키오스크 모드 예시: `chrome --kiosk "file:///경로/linkson-kiosk/index.html"`
- GitHub Pages로 배포하려면 저장소 **Settings → Pages**에서 배포할 브랜치를 선택하세요.

> 글꼴(Pretendard, Great Vibes)은 CDN에서 불러옵니다. 인터넷이 끊기면 시스템 기본 글꼴로 표시됩니다.
